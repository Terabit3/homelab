## Private configuration files

Actual passwords, API keys, and private settings are stored separately
in `E:\Homelab-Private`.

Configuration examples in this repository must not contain secrets.

## Purpose

Document how everything works, why it was configured this way,
and how to fix or rebuild it when necessary.
